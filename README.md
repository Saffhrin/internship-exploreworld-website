✈️ ExploreWorld — Travel Agency Website
---

A modern, responsive travel agency website developed during my web development internship. ExploreWorld showcases Bootstrap 5-based responsive design, semantic HTML5 structure, custom CSS theming, and an elegant UI inspired by professional travel and tourism brands.

🔗 💼 Internship Details
---

**Position:** Web Development Intern
**Organization:** Gurumantra4U
**Duration:** June-July, 2026

---

🔗 Responsibilities
---

- Designed and developed the full website using Bootstrap 5.
- Structured content using semantic HTML5.
- Customized Bootstrap components (navbar, dropdown, buttons, grid) with custom CSS theming.
- Implemented a scroll-aware sticky navbar using the Intersection Observer API.
- Implemented Header, Body, and Footer section architecture.
- Added JavaScript interactivity for navbar background transitions on scroll.

---

🔗 ✨ Features
---

🔗 🏠 Home Section
- Full-screen hero header with background image, dark overlay, and call-to-action button.
- Sticky navigation bar with dropdown menu for travel packages.

🔗 ℹ️ Intro Section
- Brand tagline with icon accent.
- Blue-themed highlight section introducing the agency.

🔗 🌍 Destination Sections
- International Tours showcase with circular image and description.
- Holiday Packages showcase with alternating image/text layout.
- Promo grid highlighting Mountains, Beaches, and Adventure tours with hover zoom effect.

🔗 📍 Why Choose Us Section
- Highlight section with icon and call-to-action.

🔗 📞 Contact Section
- Phone, email, and location details with icons.
- Clean, centered footer with copyright.

---

🔗 📱 Responsive Design
---

- Fully responsive layout powered by the Bootstrap 5 grid system.
- Custom responsive breakpoints for tablet and mobile via media queries.
- Collapsible mobile navigation menu.

---

🔗 🎨 Modern UI Features
---

- Scroll-triggered navbar style change (transparent → white with shadow) using Intersection Observer.
- Smooth color transitions on links, buttons, and promo tiles.
- Circular image styling for destination photos.
- Hover-zoom and overlay-fade effect on promo tiles.
- Custom-styled Bootstrap dropdown menu under "Packages".
- Rounded pill-style buttons.
